# 🧮 Interactive Calculator

A simple and interactive web-based calculator designed to perform mathematical calculations with ease. It features a clean interface and responsive design for a smooth user experience.

## ✨ Features

- Addition (+)
- Subtraction (-)
- Multiplication (×)
- Division (÷)
- Clear and delete functionality
- Interactive button controls
- Real-time calculation display
- User-friendly interface

## 🛠️ Technologies Used

- HTML5
- CSS3
- JavaScript

## 🚀 Getting Started

### 1. Clone the repository

```bash
git clone https://github.com/vibinsonraj05/Interactive-Calculator.git
```

### 2. Navigate to the project folder

```bash
cd Interactive-Calculator
```

### 3. Run the application

Open the HTML file in your web browser.

## 📸 Preview

Launch the application locally to explore the calculator.
